Головна | HTML | CSS

CSS — це каскадні таблиці стилів, які визначають оформлення HTML-документів. За їх допомогою змінюють шрифти, кольори, відступи та розташування елементів.

Один файл CSS можна підключити до кількох сторінок сайту. Тоді зміни в цьому файлі застосовуватимуться до всіх сторінок, що його використовують.
